# Factor Foundry

A steampunk workshop puzzle game for learning to factor quadratics with algebra tiles.

Drag x², x and 1 tiles from the tray onto the bench to build one solid rectangle. The rectangle's sides are the factors, e.g. x² + 5x + 6 = (x + 2)(x + 3).

- **S1** Apprentice set: x² + bx + c
- **S2** Journeyman set: bigger constants
- **S3** Master set: ax² + bx + c with a > 1

Controls: drag or tap tiles · R rotate · Z undo · Enter check. Progress is saved in the browser.

A single static `index.html` with no build step. Deployed on Vercel.
